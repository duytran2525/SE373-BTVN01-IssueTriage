Một lần trước khi demo

Chuẩn bị môi trường và cấu hình

1. Tạo virtual environment

cd draft/d02-3/scripts
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

2. Tạo file cấu hình

cp .env.example .env

Mở .env và điền API key, base URL và model ID của provider đang dùng.

Không hardcode key. Các demo đọc .env ở thư mục scripts hoặc ở repository root. OPENAI_BASE_URL và OPENAI_MODEL là bắt buộc. 
OPENAI_API_KEY=your_key
OPENAI_BASE_URL=https://your-openai-compatible-provider/v1
OPENAI_MODEL=provider-prefix/model-id

Demo 04 · Streamlit UI

Chạy giao diện Issue Triage

Mở form, nhập issue, bấm Phân loại issue. UI hiển thị tool trace trước final response.

streamlit run 04_streamlit_triage.py \
  --server.headless true

Terminal sẽ in Local URL. Giữ terminal này mở trong lúc dùng UI; Ctrl + C sẽ dừng server.

Tuỳ chọn

Mở Demo 04 cho thiết bị trong LAN

Chỉ dùng trong mạng tin cậy. API key không được gửi về browser, nhưng bất kỳ người nào mở URL này đều có thể khiến server gọi model bằng API key của bạn. 
streamlit run 04_streamlit_triage.py \
  --server.address 0.0.0.0 \
  --server.port 8501 \
  --server.headless true

Dùng Network URL Streamlit in ra, ví dụ http://192.168.1.88:8501. Nếu thiết bị khác không vào được, kiểm tra firewall macOS cho TCP port 8501.

Troubleshooting

Lỗi thường gặp

Streamlit hỏi Email hoặc không chạy nền

Thêm --server.headless true vào lệnh. Lần chạy đầu Streamlit có thể hỏi email; bỏ trống và nhấn Enter, hoặc dùng headless để bỏ qua prompt.

Port 8501 is not available

Một Streamlit khác đang giữ port. Dừng terminal Streamlit cũ bằng Ctrl + C, hoặc đổi sang port khác:

streamlit run 04_streamlit_triage.py --server.port 8502 --server.headless true
No active credentials for provider hoặc model_not_found

OPENAI_MODEL không tồn tại hoặc không có quyền trên gateway. Kiểm tra model list của provider rồi đặt model ID đầy đủ, ví dụ có provider prefix như gh/gpt-4.1.
